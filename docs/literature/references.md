## Citing software and datasets (IEEE §11.11 forms)

For a dataset, IEEE form: `[n] Author or Organization, "Title," version x.x, year. [Online].
Available: URL or DOI (accessed Mon. DD, YYYY).`

Two rules specific to this project:

1. **Always cite the original, not the mirror.** The Kaggle and Hugging Face mirrors carry
   incorrect licences ("Unknown", "MIT", "CC BY-SA 4.0") that contradict the upstream CC BY 4.0
   record. Cite the Mendeley/Zenodo record [1]–[7], and cite the mirror [8] only if you actually
   downloaded from it, in which case say so in the datasheet.
2. **Cite the JMuBEN record IDs explicitly.** The JMuBEN paper's "respectively" is inverted
   relative to the Mendeley record titles: `t2r6rszp5c` holds Rust/Cercospora/Phoma and
   `tgv3zb82nd` holds Miner/Healthy. Write the record IDs in the methods section so a reviewer
   does not conclude the group mislabelled the classes.

## Citation-discipline checklist before every submission

- [ ] Every in-text `[n]` resolves to an entry below, and every entry below is cited at least once.
- [ ] Every reference has been **read** (Guideline §5.4 — *"A source that the student has not read
      must not be cited, and a summary produced by an AI tool must not replace reading the
      source"*).
- [ ] Every DOI resolves.
- [ ] No AI tool is listed as an author (§11.11).
- [ ] No figure or table from a source is reproduced without acknowledgement in the caption (§11.7).
- [ ] Internet sources are supplementary, not the bulk of the list (§11.11).
- [ ] Reference count ≥ 15 for the proposal, extended for the final report (§5.5).
- [ ] The comparison table's "not reported" cells are honest — no invented metrics.
