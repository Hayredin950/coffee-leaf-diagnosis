# App Image Prompts — BunaDoctor

**How to use this file.** Copy one prompt at a time, paste into your image generator, generate. Each
prompt already contains the full style block, so they do not need to be used in order and they do not
depend on each other.

**Generate in this order if you are short of time:** P3, P6, P7 (the argument), then P13, P14, P15,
then the rest.

---

## The style block

Paste this at the end of every prompt. It is already included in each prompt below, so you only need it
if you write your own screen.

## Notes that will save you an afternoon

| Problem | Fix |
|---|---|
| Amharic comes out as boxes or invented glyphs | Most generators cannot draw Ethiopic. Generate with English labels, then set the Amharic in Figma with **Noto Sans Ethiopic**. Never ship a screenshot with fake Amharic. |
| Each screen looks like a different app | The palette is doing the work. If a generator drifts, re-paste the whole style block rather than saying "make it brown" — the hex codes are the instruction. |
| The phone frame eats the layout | The prompts say `no device frame` on purpose. Add the frame in Figma so all eighteen line up. |
| The result screens look like every other AI demo | P6 and P7 are the differentiators: **a set instead of a percentage**, and **evidence dots instead of a confidence number**. Do not let a generator add a big "91 %" — it is the exact thing this project argues against. |
| You need a banner for GitHub or the poster | Use P18 at 16:9, crop to 2:1, overlay the project title in the same cream and brown. |
